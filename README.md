The backend has been implemented to meet the required outcomes. Users can register and log in securely, with authentication ensuring proper access control.
Authenticated users are able to add and manage patient and doctor records via the backend. The system also facilitates assigning patients to specific doctors.
All data, including user credentials and medical records, is securely stored in a PostgreSQL database, ensuring data integrity and privacy.

Also, an http file has been created to test all the functionalities, just place the REFRESH_TOKEN and ACCESS_TOKEN at assigned places.
